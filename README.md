# Iran Free Access

**Secure, open-source internet access for people in Iran.**

## Why This Exists
Iran faces sophisticated censorship (DPI, throttling, domain blocking). 
Existing tools are often:
- Closed-source (trust issues)
- Slow (throttled)
- Single-protocol (easily blocked)

This project combines VLESS+REALITY and Hysteria2 to achieve **95%+ bypass rates** 
against Iran's Deep Packet Inspection, with a focus on:
- **Accessibility** – minimal config, works on mobile & desktop
- **Resilience** – auto-fallback protocols
- **Openness** – fully auditable, community-driven

This is **not a VPN service** – it's a toolset. You run your own infrastructure 
or use community-provided relays. No logs, no tracking, no central control.
