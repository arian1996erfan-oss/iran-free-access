By participating in this project, you agree to:
- Be respectful and inclusive
- Focus on the mission – helping Iranians access free internet
- Keep discussions technical and solution-oriented
- No political or religious debates

## 🚀 Getting Started

### 1. Fork the Repository
Click the **Fork** button at the top right of this page.

### 2. Clone Your Fork
```bash
git clone https://github.com/YOUR_USERNAME/iran-free-access.git
cd iran-free-access

### 3. Create a Branch

```bash
git checkout -b feature/your-feature-name
```

### 4. Make Your Changes

Add your code, docs, or translations.

### 5. Commit and Push

```bash
git add .
git commit -m "Brief description of what you did"
git push origin feature/your-feature-name
```

### 6. Open a Pull Request

Go to the original repo and click "New Pull Request".

---

### 📝 Development Workflow

1. Check existing issues – see if someone is already working on it
2. Comment on the issue – let others know you're taking it
3. Work on your branch – keep changes focused
4. Write tests – if adding code, add tests
5. Update docs – if changing functionality
6. Submit PR – with clear description of what you changed

---

### 🎨 Style Guidelines

Code

· Language: Follow standard style for that language
· Comments: Write clear comments in English
· Naming: Use descriptive names (no abbreviations)

Documentation

· README: Keep it up to date
· Comments: Explain why, not just what
· Farsi docs: We'll maintain parallel Farsi documentation

Commit Messages

· Use present tense: "Add feature" not "Added feature"
· Keep under 50 characters for the subject line
· Use body for more detail if needed

---

### 🐛 Found a Bug?

1. Check if it's already reported in Issues
2. If not, create a new issue with:
   · Description of the bug
   · Steps to reproduce
   · Expected vs actual behavior
   · Screenshots if applicable

---

### 💡 Have an Idea?

Open an issue with "Feature Request" in the title and describe:

· What problem it solves
· How you envision it working
· Any alternatives you considered
